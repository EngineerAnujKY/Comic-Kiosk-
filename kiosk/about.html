About the project

Project details

  • Title: Comic Books And Graphic Novels Kiosk Storefront
  • Course: CSE326 Internet Programming | CA1
  • Target users: Comic collectors and graphic novel readers
  • Problem: Collectors struggle to find organized collections, condition grades and release schedules for comics, manga volumes and trade paperbacks.
  • Solution: A collector-oriented storefront with collection checklists, CGC-style grading and a release calendar, built as a frontend only.
  • HTML
  • CSS
  • JavaScript
  • localStorage
  • Razorpay test mode

Features

  • Catalog of 16 titles with format, genre and publisher filters
  • Collection checklists with a progress bar
  • Condition grades with live pricing
  • Release calendar with a wishlist
  • Reviews, cart, accounts and test-mode checkout

Demo project: all data is sample data, accounts and checklists live only in your browser, and no real payment is taken.
